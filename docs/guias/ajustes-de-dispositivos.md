## Roteador

:::warning Dicas

Se usa o DNS do provedor, ele pode bloquear sites e [manipular](https://www.reddit.com/r/HomeNetworking/s/jyoxEamZWm) seu TTL. 

Como [posicionar](https://www.tp-link.com/br/support/faq/455/) melhor o roteador.

Ligue os equipamentos por cabo [direto no modem](https://forum.adrenaline.com.br/threads/problema-serio-com-bufferbloat.692012/post-1075993822).

Entenda os tipos de [implementação](https://forum.adrenaline.com.br/threads/configuracao-de-roteadores-repetidores-dicas-duvidas-e-configuracoes.682601/) de roteadores.

Use o [WinMTR](como-instalar-e-usar-o-winmtr.md) para diagnosticar alta latência e perda de pacotes.

O que é e como resolver o [Bufferbloat](https://vmia.com.br/o-que-e-bufferbloat-como-resolver/).

Como instalar o OpenWRT no [Raspberry](https://viniciuspaes.com/openwrt/tutorial-resolver-problema-bufferbloat-openwrt/).
:::

- **DNS:** Verifique com [DNS Speed Test](https://controld.com/tools/dns-speed-test)
- **MTU:** Padrão (altere se houver problemas)
- **WPS:** Desativado
- **Band Steering:** Desativado
- **Largura de banda:**
  - **2.4 GHz:** Mínimo
  - **5 GHz+:** Máximo
- **Canal:** Verifique com [Acrylic Wifi Analyzer](https://www.acrylicwifi.com/en/wifi-analyzer/)
